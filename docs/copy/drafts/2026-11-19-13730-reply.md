One addition to the "only supported way out" section, because the way out does exist and it does not recur.

In the 0.2.2-rc.5 build installed here (Windows), the desktop's own CLI entrypoint runs the ordinary `dsh` CLI with `manageDesktopProfile: true`. That flag guards exactly one call site — `dsh plugin --profile desktop …`. The "managed exclusively by the Electron application" refusal that #13748 hit is on the *boot* path and has no such guard, which is why `--dump-config` reads as "there is no way in" while `plugin add` has one. The Windows report got out that way:

```bash
ELECTRON_RUN_AS_NODE=1 "<install>/<resources>/app.asar/dsh/node_modules/@deepseek-ai/dsh-desktop-host/lib/cli.js" \
  plugin --profile desktop add \
    @deepseek-ai/dsh-experimental-session-search@0.2.2-rc.5 \
    @deepseek-ai/dsh-experimental-terminal-bundle@0.2.2-rc.5 \
    @deepseek-ai/dsh-experimental-inspector-profile@0.2.2-rc.5
```

Quit the app first — the command takes a lock on the profile manifest. Two subcommands live on the same path: `version-exemptions` prints what is currently in `compatibility.json`, and `revoke-version <pkg@version> --dsh-version <exact>` removes an entry. The entry you hand-wrote is the file those commands write, and `allow-version … --accept-risk` (with its "can corrupt data" warning) is the supported way to grant it while the versions still differ.

One detail behind your first management gap: `dsh-experimental-session-search@0.2.2-rc.3` declares no DSH requirement at all, so the preflight has nothing to deny on the bundle — the denial lands on the rc.3 packages it pulls in, and those pin exact rc.3 peers. Bundle metadata and row resolution are two different answers; only the second one is what you needed.

Whether `add` also drops the stale rc.3 row that shadows the installation's copy is your run's result to observe, not mine — I read the code paths, not your profile. That gap (updater should align before it applies, which is what #11554 asks for) is the durable fix; the command above is only the manual version of it.

Boundary: this is read out of the archive on one Windows machine and was not run on macOS; it is not your machine.
