## 可以说什么

- 上面那段（`Failed plugins`）才是根因；`Plugins waiting for services` 是后果。
- 二分法（他自己也提了，我们的版本补上「怎么记」）：把 `dsh.profile.bundles` 缩到只剩官方 base 的 2 条 → 确认能起 → 一次加回一个 → 崩在哪个就是哪个。**每次改之前先把 `dsh.profile.bundles` 复制一份**，因为改回去要逐字节还原，靠手抄容易漏。
- 分清两个阶段的话术：准入（admission）在 `import` 之前就把行判掉，**不会有运行期堆栈**；运行期（import / apply / 上下文注入）才有栈。11-11 那条已经用同一个引擎把两款插件判成 `admitted`，所以这次更可能是后者。
