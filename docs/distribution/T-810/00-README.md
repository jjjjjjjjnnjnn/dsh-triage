# T-810 · 分发草稿（agent 起草，HUMAN 发布）

> **这一页是什么**：`docs/ROADMAP.md` §2 的 **D5** 要求「2 周内 reactions ≥10 · 外部引用 ≥1 · 周下载 ≥20」。
> D5 缺的从来不是功能，是**一次真实接触**。这个目录里是那份接触的素材：五篇草稿 + 一份机器可查的登记表。
>
> **状态：全部是草稿，一篇都没有发出去。** 发布是 HUMAN 的动作（`docs/HANDOFF.md` §3），agent 不代发。

## 一条不能破的规则

每篇只允许引用**真机产物**，并且只能引用 `registry.json` 里登记过的那几个；`node scripts/check_listing.mjs` 会
逐条复算被引用的产物 sha256，并对「升级会修好」「已收录」「全量」这类话说红。改数字不重跑 = 红。

## 发布之后要做什么（这一步没有捷径）

1. `node scripts/record_market_baseline.mjs --stamp <新 ISO>`：把当天的下载数字与**形状**记进 SSOT（D5 只认 `steady`）；
2. 在 `registry.json` 里把对应草稿的 `status` 从 `draft` 改成 `posted`，写上 URL 与日期；
3. `docs/HANDOFF.md` 里更新 D5 的三个数（reactions / 外部引用 / 下载形状）。

## 五条不许写

1. **不写「升级会修好」**——`improved` 今天仍是 0，`BS-42` 明说这是降级几何；
2. **不写「全网 / 所有插件」**——我们扫的是 npm 关键词命中的 1,584 个（关键词口径，不是全量）；
3. **不写「已验证 / 官方推荐」**——我们与上游没有任何隶属关系；
4. **不写个人身份**（真名、社交号、单位、邮箱）——HUMAN 2026-10-29 的决定，只是项目口吻；
5. **不贴绝对路径**——产物里出现的本机路径一律用 `<dsh-home>` / `sandbox/upstream/…` 指代。
