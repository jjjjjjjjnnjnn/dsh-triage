# ADR 0009 · 会话作用域读数要不要破铁律 4（`T-202a` / `T-303`）

> **状态**：**proposed —— 未授权，未实施**。本文件只把「要不要允许探针使用一次会话凭据」变成一道可签字的题；它本身**不改任何代码、不记任何凭据**。
> **卡住的是什么**：`T-303`（`namespace-diff`：列出「声明了但没注册」的工具）需要 **agent/preset 作用域**的工具表面；进程级探针只能看到全局层 **1 个**工具（`BS-21`），上游插件也不静态声明工具名（`BS-22`）。没有会话就看不到那一层。

## 背景（全部是已记录的实测，不是推测）

| 事实 | 证据 |
|---|---|
| 进程级能力读数只到全局层（1 个工具），拿不到 preset 的工具表 | `data/results/capabilities-2026-10-27T23-30-00.000Z.json`，`outcome=expectation-not-met`；`docs/specs/M2-capabilities.md` 的 B1/B2 |
| 上游插件不声明工具名：`bash` 只存在于 `defineTool({ name })` 的构建产物里 | `MSG`/`F` 记录见 `docs/specs/M2-capabilities.md` §7（`BS-22`） |
| 「声明 vs 注册」的差异只有**会话里**才看得见 | `docs/BACKLOG.md` T-202a 的重定义（R13 取证后） |
| 铁律 4：不得读 `~/.dsh/credentials`、不得向沙盒注入真实凭据 | `PROJECT_RULES.md` 严禁行为第 4 条；`docs/adr/0004` 的外部候选边界 |

所以问题不是「怎么实现」，而是**「为了 T-303，要不要允许一次性的、用户主动提供的会话凭据进入探针进程」**。

## 三条路（互斥，选一条）

| 方案 | 做法 | 代价 | 与铁律 4 的关系 |
|---|---|---|---|
| **A. 维持现状（不做）** | `T-303` 保持 `unmeasured`；对外只说「进程级能力清单 + 两样本差分」 | `namespace-diff` 永远缺；`M4` 面板里的「工具没注册」只能靠 `unknown` | 完全合规 |
| **B. 用户显式提供一次性会话**（推荐，但需要签） | 新命令 `triage session-snapshot --session-from-stdin`：用户把会话 token **从 stdin 喂进去**（不进磁盘、不进环境变量、不进产物），探针用它连一次 `pluginInventory`/工具表 Remote，读完立刻丢弃 | 要新增一条读凭据的路径；要在产物里证明「只用了这一次、没落盘」 | **破例**：需要本 ADR 被签，且必须写死下方 6 条边界 |
| **C. 让别人替我们读** | 由上游/Desktop 侧提供会话作用域快照，我们只消费文件 | 依赖第三方；短期拿不到 | 不破例，但也不解决（等同 A + 等） |

## B 案的可机器检查边界（若被授权）

1. **只从 stdin 读**：不接受 `--token`、不接受环境变量、不接受文件路径；进程退出后任何地方都找不到它。
2. **只用一次**：单个会话快照 = 单次 Remote 调用；不缓存、不复用到下一次运行。
3. **产物零凭据**：`data/results/*.json` 里不得出现 token、cookie、URL 查询串；`results-privacy` 门必须对这一类产物同样生效（新增断言）。
4. **不进沙盒**：会话凭据只用于**只读的 Remote 读取**，不得传给任何 `pnpm`/候选子进程；`scrubbedEnv` 与 `sandboxNpmEnv` 的语义不变。
5. **失败即 `unknown`**：拿不到会话、会话过期、Remote 拒绝 → 一律 `unknown` + `missing.session-scope`，**不得**降级成「工具没注册」。
6. **可复算**：产物必须记下「用了哪个端点、读了哪些字段、耗时」，但不记凭据本身；重放时要求用户重新提供会话（这是特性，不是缺陷）。

## 不建议把 B 案做成默认路径的理由

- **它只服务一个断言**（`namespace-diff`），而今天的 `unknown` 是诚实的；为了一个断言让「读凭据」成为产品的一部分，需要非常明确的收益证明。
- 一旦接受「用户主动喂凭据」，下一次就会有人问「能不能自动读 `~/.dsh`」——那就退化成铁律 4 的反面。
- 当前的替代品已经能回答大部分问题：行级 admission、相位、能力清单、复制组合实测（T-304）。

## 签字区（HUMAN）

```
[ ] A. 维持现状：T-303 继续 unmeasured，不做会话作用域读数（推荐，零风险）
[ ] B. 授权一次性会话读数（破铁律 4），并把上方 6 条边界写进 `PROJECT_RULES` 的例外条款
[ ] C. 等上游/Desktop 提供快照接口，本轮不动
```

> 未勾选前：`T-202a` / `T-303` 保持 ⛔（退出条件：本 ADR 被签 + 边界 1–6 有机器检查），且**不许**用「进程级工具清单」冒充会话作用域结论（`BS-21`）。
