# 模拟用户测试 · DSH 设置页「分诊台」（R51，2026-10-30）

> 对象：`packages/plugin/client.js` 渲染的 DSH 设置页页签（`settings.plugins.tab`）。
> 方法：**真机沙盒 Host + 真浏览器（Edge headless / CDP）**，脚本 `scripts/record_client_serve.mjs`
> 把屏幕上的文字原样取回（`tab_probe.text`），测试者**只读这一屏**——不读 README、不读 HANDOFF。
> 每次跑落 `data/results/client-serve-<stamp>.json` + `.sha256`，可复算。

## 1. 测试协议（一个陌生人的五个问题）

| # | 任务（模拟） | 怎么判（机器判据） |
|---|---|---|
| Q1 | 我从终端/市场页听说有个「分诊台」，**在 DSH 里怎么找到它** | `visible` 的 hop 链必须走通，且标签出现在 DOM |
| Q2 | 打开后第一句话：**我这套装会不会坏？** | DOM 里存在结论句（`data-triage-tone` 有值） |
| Q3 | **是哪一条？** | 有具体行（`issues > 0`）或明确写「没有需要你动手的行」 |
| Q4 | **我该敲什么？** | 屏幕上出现可粘贴的 `dsh-triage …` 命令 |
| Q5 | **等了多久？** | 点开页签到出现结论的毫秒数 |

## 3. 发现的缺陷与处理

| # | 屏幕上的现象（原文） | 为什么是问题 | 处理 |
|---|---|---|---|
| F1 | `逐行归因dsh-triage why` | 标签与命令**粘成一串**：间隔原本交给宿主 CSS，取回的文本里没有分隔符——真实页面里可能同样难分辨 | 已修：分隔符写进文本本身（`逐行归因 — dsh-triage why`），并加单测钉住 |
| F2 | `…所以我们判断不了。 row timer 引入的 … 未安装` | 引擎原因（含英文 `row` 词）与结论句**并排粘连**，陌生人分不清哪半是结论、哪半是细节；且「未安装」容易被读成「需要安装」 | 已修：原因改成从属标注 `· 原因: …`（英文 `· reason: …`），并加单测 |
| F3 | `也可以开本地面板：dsh-triage serve` + 下一步里也有 `打开本地面板 — dsh-triage serve` | 同一件事说两遍，屏幕变长、重点变散 | 已修：删掉重复那行 |
| F4 | `同一份证据、同一条 messageId` | 面向插件作者的术语，陌生人第一段就被挡了一下 | 已修：提示行改成「结论由命令行同一引擎在宿主侧算好，这里只负责显示。」 |
| F5 | 三条问题行**句式完全相同**（都因为「依赖在本 profile 下未安装」） | 不是文案 bug，是这份沙盒 profile 的性质：三行抖出同一个原因。真实 profile 会多样；但「三条一样的行」很占屏幕 | **未修**，记进 `BS-47`：只在 `more > 0` 时保留前 3 条是对的，是否符合真实分布需要**有被拒行**的 profile 才有见证 |

## 5. 边界（这些没有被测到，不要读成「已验证」）

`BS-47` 写着同样的内容，这里只列要点：

1. **「会坏」那一屏没有真机见证**：四次跑的沙盒 profile 都是 `会坏 0`；被拒行的视觉与「复制修复命令」按钮只有单测。
2. **只有中文屏**：`en` 走同一段代码，但没有一张英文截图。
3. **一个浏览器（Edge headless）、一个 profile、一个 DSH 版本（0.2.1-rc.4）**。
4. **剪贴板没有被交互见证**：`navigator.clipboard` 成功与否不改变屏幕，但也没人真点过。
5. `user-answer` 是**结构性判据**：它证明「有结论 / 有行 / 有命令」，**不证明句子可读**——可读性由这份报告的人工阅读部分承担。

## 6. 复算

```powershell
node scripts/record_client_serve.mjs --dsh-main sandbox/upstream/0.2.1-rc.4/install/node_modules/@deepseek-ai/dsh/lib/bin.js --install sandbox/upstream/0.2.1-rc.4/install --stamp <新 ISO>
```

每次跑必须给新的 `--stamp`（旧 stamp 会被拒绝，以免覆盖证据）。同一命令、同一沙盒，跑出来的
`steps[].status` 与 `tab_probe.text` 就是这张屏幕的证据。

读了这份报告的人应当能回答：**这个页签回答了陌生人的三个问题，用 0.9 秒；但它「有坏东西」的那一面还没被看见过。**
