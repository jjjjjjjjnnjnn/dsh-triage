## 2. 正确性

**PASS。** 三个可判定的断言，每个都有真跑产物：

1. **复制路径能给出 `go`，而且证据是完整的**：`copy:upstream` + `ok-plugin` → `boot→sample 7.4s` / HTTP **401** / 渲染 **2182ms**（`#root` + 289 字符）/ 候选行 `include:triage-probe-ok` **active** / `candidate_registered=true` / `registry_auth_used=false`。
2. **两种负形状都停在 `unknown`，且没有走过 `install`/`boot`**：不可用副本的 `steps` 只有 `runtime`/`profile`/`cleanup` 三步；断言 `boot-sampled`、`http-served`、`inventory-active` 全部 `unmeasured`（不是 `failed`）。
3. **F40 的「假成功」被真正挡住**：悬空链接那次的 `profile_copy.install.exit_code = 0`，而 `dangling_links` 仍点名 `local-thing → link:./not-here`，结论 `unknown`。

## 3. 可复现

**PASS。**

- 一条命令重放每一种形状（`--copy-profile <name>` + `--dsh-home <home>`），产物 + `.sha256` 落 `data/results`；
- 两个负夹具是**文件系统级**的最小复现（`tests/fixtures/probe/profile-copy/{unusable,dangling}/profiles/web/package.json`），不依赖网络状态；`unusable` 用 `FETCH_404` 判，`dangling` 用 `link:` 判；
- 单测把三条规则钉死：只复制白名单（`.npmrc`/`node_modules`/`.plugin-manager` 必须不在副本里）、`link:`/`file:` 的 stat 语义（含悬空符号链接）、被拒名单解析必须跨行；
- 模板路径的「不变」也有断言：`prepareProfile` 不被调用、`profileOrigin === 'template'`、计划里没有 `profile` 步。

## 4. 合规与许可

**PASS。**

- 副本**只读**真实 profile 的四个声明文件；`.npmrc`（可能带 registry token）**从不复制**，`node_modules` 与 `.plugin-manager` 也不搬（`profile-copy.ts` 的注释与单测同时锁定）；
- 沙盒**不批准任何构建脚本**：`strictDepBuilds: false` 只把 pnpm 的「错误」降成「提示」，`onlyBuiltDependencies` 保持为空；被跳过的包逐个进 `install.ignored_packages`——这是 ADR-0004「不 vendor、不判安全」的同一口径，而不是偷偷允许执行第三方脚本；
- 本轮无新外部候选、无新 vendor 条目；`quarantine/` 未动。

## 6. 对抗性（专门证明本轮会出错的地方）

| # | 注入/反问 | 结果 |
|---|---|---|
| A1 | **「装不上就直接 `blocked`，反正候选有问题」** | 反例成立：候选根本没被安装（`steps` 只有三步）。若判 `blocked`，任何一个依赖私有源的组合都会变成「插件坏」。已固定为 `unknown` + `missing.probe` |
| A2 | **「install 退出 1 但继续 boot，看看行在不在」** | 反例成立且**实测**：pnpm 非 0 退出时 `dsh.profile.bundles` 不变（F42），boot 会成功但行不存在 → `row-missing` → `blocked`。这是把包管理器策略算到插件头上的典型案例，已由读回组合挡住 |
| A3 | **「被拒名单里没候选就一律放行」** | 反例成立：名单读不出来时必须保守。单测 `an unreadable ignored list keeps the conservative block` 与 N36 钉死 |
| A4 | **「`strictDepBuilds: false` 就是偷偷允许构建」** | 反例不成立：`onlyBuiltDependencies` 为空、`Ignored build scripts:` 照旧打印、被跳过的包逐个记账。这条边界写进 `BS-30` 与 `T-315`（要 ADR） |
| A5 | **「复制模式 `go` = 在我机器上验证过」** | 反例成立：沙盒从不构建原生模块（`BS-30`），副本也不搬 `node_modules`（`BS-31`）。对外口径已改成「声明层一致、依赖装齐、原生模块未构建」 |
| A6 | **「`--profile` 默认值 `web` 无所谓」** | 反例成立：会让 `--copy-profile upstream` 静默改名，测到的是另一个 `profiles/<name>`。已用 `profileExplicit` 区分，单测 `a copy plan … keeps the source profile name` 钉住 |
| A7 | **「复制源可以和沙盒重叠，反正会清理」** | 反例成立：重叠会让探针覆盖它声称要测量的组合。`profile-source-overlaps-sandbox` 双向拒绝，单测覆盖「沙盒在源里」与「源在沙盒里」 |
