## 2. 正确性

**PASS。** 两个可判定的断言：

1. **凭据继承是真的，且已被关掉**（黑盒对照，**从未读凭据文件**）：

   | 场景 | `An authorization header was used` | 安装结果 |
   |---|---|---|
   | 默认环境（继承 `~/.npmrc`） | **true**（2/2） | `ERR_PNPM_FETCH_404` |
   | `npm_config_userconfig` → 沙盒内空文件 | **false**（2/2） | 同样 `ERR_PNPM_FETCH_404` |

   两个方向都对：既证明「原来真在发 token」，也证明「关掉之后不影响安装与归因」。
2. **耗时不再是「感觉」**：本机 156 行真实 profile 实测 `load` **376–690ms**（3 次），夹具 18ms；`/api/audit` 是同步扫描，期间阻塞事件循环——这一点写进 spec 与坑表，而不是留一句「应该很快」。

## 3. 可复现

**PASS。**

- 凭据对照是**同一台机器、同一条候选、两种 env**，各跑 2 次；对比的是 pnpm 自己打的日志行，不是我们的推断。
- 单测把两条规则钉住：`sandboxNpmEnv` 必须把 userconfig 指向沙盒且文件为空、且不动其他变量；`run.installAuthUsed` 必须如实转述 pnpm 的话。
- 冒烟 `node scripts/record_serve_smoke.mjs --stamp <iso>` 一条命令重放（14 项）；产物里不写 token、不写端口。
- T-304 的三个 spike（复制即启动 / 装依赖后再启动 / `link:` 假成功）都给出了可重放的最小步骤，写进 spec §8.5。

## 4. 合规与许可

**PASS（并且这一轮是**加强**合规）。**

- 修的是**我们自己的**行为：以前沙盒读 `~/.npmrc` 并把操作者 token 发给 registry，这违背 `PROJECT_RULES` 铁律 4 与 ADR-0004 §3 的**本意**（虽然字面上我们没「注入」）。修法只是**停止继承**，没有读、没有复制、没有记录那份文件。
- **代价已写明**：沙盒不再继承操作者的 npm 用户配置（含镜像）。需要私有源的形状仍走 profile 级 `.npmrc`（T-305b 已验），所以能力没丢，只是口径变严格。
- 本轮没有新增外部候选，没有新增 vendor 条目；`link:`/`file:` 的「假成功」没有下载任何东西。

## 6. 对抗性（专找「这个修复可以被绕过」）

| 注入 | 期望 | 结果 |
|---|---|---|
| 把 `npm_config_userconfig` 改回真实路径 | `registry_auth_used=true` | R20 对照 2/2；字段会把它暴露出来 |
| 只设小写 `npm_config_userconfig` | 某些 npm 兼容工具读大写 → 仍泄漏 | `sandboxNpmEnv` 两个拼写都设，单测断言 |
| 只删环境变量、不碰 userconfig | 凭据照发（这正是修复前的状态） | 单测断言的 `userconfig.startsWith(dshHome)` 会红 |
| 认为 `/api/audit` 很快、不用计时 | 「面板慢」无法定位 | 响应头 + 单测（含 409 路径）+ 冒烟检查 |
| 用 `link:` 依赖「装成功」冒充组合可用 | 会给出假绿 | 已写进 T-304 退出条件（逐个 stat），本轮**不实现**所以**不声称**能判 |
| 把 `ADR-0006` 当成已批准、顺手改默认窗口 | 阈值被悄悄改掉 | ADR 状态是 proposed，签字区为空；spec §4 数字未动（git diff 可查） |

**没找到反例的部分**：`sandboxNpmEnv` 在**非 Windows** 上是否同样生效（未测；pnpm 的 userconfig 解析与平台无关，但没有真跑）；`~/.pnpmrc` / `PNPM_HOME` 是否还有第二条继承路径（未测，已在下面记为遗留）。

## 7. 本轮结论与遗留

- **交付**：凭据不继承（含可见字段）、面板耗时可见、ADR-0006（待签）、T-304 取证完成。
- **遗留（新）**：
  - `BS-29`：**还有别的凭据继承路径没验证**——`~/.pnpmrc`、`PNPM_HOME`、系统级 `npmrc`（`%ProgramData%\npm\etc\npmrc`）都可能被 pnpm 读到；本轮只堵住 user config 这一条，**不要**说「沙盒绝不会有凭据」。
  - `T-313`：`.npmrc` 之外的凭据来源审计（含 `corepack` / 环境代理变量）。
- **下一步**：`docs/HANDOFF.md` §3（T-304 实现 → 签 ADR-0006 → T-401 契约 spike）。
