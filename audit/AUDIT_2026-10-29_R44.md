## 4. 三处自己抓住的缺陷（都当场修）

1. **`control-has-no-new-denials` 的定义在"今天已经有坏账"的 profile 上恒假。** 旧定义是 `counts.would_be_denied === 0`；混合 profile 里 `dsh-plugin-gate` **今天就被拒**，于是 `--to <当前运行时>` 也会报 1 个 `would-be-denied`，检查判红。真正的恒等式是"**没有单元新变坏**"——每个 `would-be-denied` 都必须 `already_denied_at_current: true`。旧定义在模板 profile 上是**真空通过**（那里 0 拒），所以 R42 从没暴露它。红产物 `06-25` 原样保留。
2. **产物写的是离线视角。** `--registry` 下 CLI 会把注解挂上去，但记录器把第一次（离线）判定的 `impact`/`units` 写进文件——**文件里根本没有它声称要证明的注解**。改为"文件描述这次真正跑出来的视图"，并把离线计数单列成 `offline_counts` 用于比较。
3. **`composition` 字段写死成"模板 profile"。** 混合 profile 跑出来却说自己是模板（`declared_dependencies` 因为一个 `value` 拼写错误恒为 `null`）。改为从 profile 自己的 `package.json` 读 pins，读不到才说模板。

## 6. 对抗性：`improved` 能被怎么骗过，以及为什么现在骗不过

| 反例 | 结果 |
|---|---|
| "registry 上有个更宽松的版本" ⇒ 写 `improved` | 结构上不可能：注解在**分桶之后**才挂，且新检查 `improved-carries-no-registry-annotation` 直接断言改善单元的 `suggestions` 为空 |
| 拿"今天的拒"当"升级会修好它"，而拒因是声明本身写坏（`workspace:*`、非法区间） | `classify()` 要求至少一条 `unmet.failure === null`；本轮的 `dsh-plugin-gate` 就是反例载体——它今天拒、目标也拒，落 `would-be-denied` 而不是 `improved` |
| 拿两个不同版本各判一次，拼成"变好了" | `improved-single-version` 断言 `unit.version` 唯一，且两侧都用同一个 manifest 求值 |
| 把目标改成"任何不等于当前的版本" | 控制组断言 `--to <current>` 的 `improved = 0`；`dsh-noname-kit` 在 `--to 0.3.0` 上落 `would-be-denied`（单测钉住） |
| 用"四桶里三桶"冒充四桶 | `all-four-buckets-non-empty` 直接读 `counts` |
| 把策展组合说成随机抽样 | 产物 `source.composition` + `declared_dependencies` 明写"选哪些包是我们的选择"，`limits[]` 再写一遍 |

## 7. 边界（不许说过头）

- **降级几何 ≠ 升级会修好它**。本轮三次 `improved` 的目标 `0.2.1-rc.3` **比当前 `0.2.1-rc.4` 旧**（`target_relation: older`）。对外只能说"**目标版本会放行它**"；"升级会修好"这句话在今天的生态里**没有样本**（前向 0/1584）。
- **策展组合不是随机样本**：6 个包是按"四桶全覆盖"挑的，声明是发布原样、没改，但选谁是我们决定的。
- **声明层判断**：没有 boot 过 `0.2.1-rc.3`，也没验证它存在与否（目标是假设输入）；`improved` 说"区间会放行它"，不说"插件能工作"。
- **单机单 profile**：`BS-38` 未变——答案只对 `mixed` 这个 profile 成立。
- **扫描不是普查**：关键词搜索 + `<name>/latest`，不是全量版本、不是全生态。前向 0 是"**这一批里**没有"，不是"生态里不存在"。

## 8. 与 R42 的关系

R42 的 `improved = 0` **不是 bug**：那份 profile 里 192 个单元全都精确钉 `0.2.1-rc.4`，结构上不可能出现"今天拒、目标放行"。本轮把这件事从"样本没有混合区间"推进成一条**可复算的生态事实**（1584 个包里前向 0），并给出了能触发它的真机组合。对外口径从"四桶里三桶有真机证据"改为"**四桶都有真机证据；其中 `improved` 只有降级几何的见证**"。
