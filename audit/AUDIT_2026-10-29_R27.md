## 2. 四轴

### 2.1 正确性

- **`{error}` 与 `settled:false` 的对照终于完整了**：前者等满窗口（5204ms/5000ms），后者 0ms（R26）。两条都有真机或真实-hook 证据。
- **D2 的红不是代码回归**：超时发生在**样本到达之前**（`wait_ms=16201`），而 E 只影响样本**之后**的等待（`replacement_waited=false`）。这一点必须写进对外口径，否则会被误读成「E 把预算搞坏了」。
- **A′ 的代价被实测推翻**：上一轮我用 R19 批次的最大 `wait_ms`（7686ms）推断「10s cap 不会误伤」，本轮同一条候选在不同时刻是 16.2s / 18.0s，**推断不成立**——ADR 已按实测改写，签字区也据此调整推荐项。

### 2.2 可复现性

- 六份新产物全部由脚本真跑（命令在 `step_reviews` 的 `real_test.command`），sha256 由门重算。
- 矩阵与 R19 用**同一份计划**（`matrix-r19.json`），因此「同 pin、同机器、不同时刻」的差异可以直接对比。
- 已知不可复现面：墙钟与样本时刻（`BS-32`，本轮从「区间」升级为「跨过预算线」）。

### 2.3 合规 / 许可

- 本批**没有新增外部候选**：真实候选全部是 R18/R19 已登记的 pin 版本；`quarantine/` 未动。
- `--hook-config` 是诊断开关：产物带 `sandbox.hook_config`（脱敏）+ 一条 `limits[]` 说明「这笔测的是仪器」，`record_probe` 另在 stderr 打 WARNING。**这类产物不得计入通过率**（矩阵/d2 都不读它）。
- 未读任何凭据；沙盒仍在临时目录、跑完即删。

### 2.4 SSOT 一致

D2 的红同时出现在：`docs/ROADMAP.md` §2、`docs/HANDOFF.md`（§2 未通过的门槛 + §3 第一条）、`audit/blind_spots.json`（BS-28 升级 + BS-32 扩展）、`docs/BACKLOG.md`（T-309 / T-311 / 新 T-317）、`docs/adr/0008`。五处对同一件事的描述一致，且都写明「没有放宽阈值、没有删 run」。

## 3. 对抗性（证明这轮不是「挑好看的说」）

| 反例 | 结果 |
|---|---|
| 「重跑矩阵直到全绿」 | **没有**。矩阵只跑了一次；只对超时的那一条做隔离复测（2 次），且三个观测值全部入账 |
| 「16.0s 那次说明是偶发，可以忽略」 | 另一次是 23.8s。三次里两次超 20s，**不能**忽略；结论写成「边界抖动 + 结构重叠」 |
| 「把红项归因于机器忙」 | 两次隔离复测是**串行、无并发负载**跑的（前一条结束才开始），所以只能算边界抖动 |
| 「把 `projection-missing` 冒充 `inactive-context`」 | 明确否定：`inactive-context` 只有桩级证据，真实 Host 那条 dead-context 竞态无法按需制造，四处写明 |
| 「`nodeLinker` 的 `go` 等于布局已验证」 | 明确否定：产物不记 `node_modules` 布局，只证明「不误判」 |
| 「D2 红是因为 E」 | 明确否定：`replacement_waited=false`，超时在样本之前 |
| 「用 exit code 判断 D2 结果」 | 发现 `d2_report` 判定失败仍 exit 0（R18 的既有决定，有测试钉住）→ 新开 `T-317`，并提醒任何自动化不得以退出码判 D2 |

## 5. 口径（可直接引用）

> **R27 之后**：`{error}` 与 `settled:false` 的等待行为都有真机/真实-hook 证据（前者等满窗口，后者 0ms）。post-E 的 D2 第一次判红，红项是 `boot-budget`（11/12），**不是** E 引起的——`dsh-mcp-connector@0.2.83` 的 tree 需要 10.6–18.0s 才稳定，`boot→sample` 三次是 16.0 / 22.5 / 23.8s。这是 20s 预算与 `settle ≤15s` 的结构重叠（`BS-28`），三条出路都要 HUMAN 签。
>
> **不许说**：①「D2 通过」（这批是红）；②「E 让预算变差」（超时在样本之前）；③「A′ 不会误伤」（已实测会，代价是一个 `go`）；④「`inactive-context` 已真机回归」（只有桩级）；⑤「nodeLinker 布局已验证」（只验证了不误判）。
