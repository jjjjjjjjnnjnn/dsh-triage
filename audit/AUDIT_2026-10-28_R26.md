# AUDIT · R26（2026-10-28）· `ADR-0008` 方案 E 实施

> **范围**：把「不可判的树要等多久」这道已签的题落成代码，并让「等没等」变成产物里的显式事实。
> **一句话结论**：**E 已实施，判据与阈值一字未动**；不可判的 `boot` 步 **48.4s → 28.6s**（同一夹具），三条回归全过，`d2_report` 复算仍 `gate.passed=true`。

## 2. 四轴

### 2.1 正确性（correctness）

- **判据没动**：`isUsableSample()` 的 diff 为空；`measurementState()`、`judgeProbe()` 的 diff 为空。`settled:false` 与 `{error}` 依旧只能出 `unknown` + `missing.inventory`，`blocked` 依旧只允许 `valid` 读数。
- **循环的四段判据**：`readable`（有样本、无 `error`）→ `timeout` → `replacedEnough`（**只在不可读时**成立）→ `startupFailed`。与旧顺序 `accept(usable|timeout) → replacedEnough → startupFailed` 相比，只有一处语义变化：**`settled:false` 不再进入 `replacedEnough`**——这正是 E。
- **`waited` 的定义**：只有在「手里已有一份样本、仍要去睡 250ms」时置真。用布尔而不是 `sampleWaitMs - sampleMtimeMs`，因为后者在 `settled:false` 与「样本晚到」两种情形下会重名。
- 单测 4/4 通过；`slow-overrun` 仍 `unknown`、`slow-plugin` 仍 `go`、真实候选仍 `go`。

### 2.2 可复现性（reproducibility）

- 三份产物由 `scripts/record_probe.mjs` 真跑，命令写进 `audit/step_reviews.json` 的 `real_test.command`；sha256 由门重算。
- `d2_report` 用**既有**矩阵（`probe-matrix-2026-10-28T11-40-00.000Z.json`）复算 → `data/results/d2-2026-10-28T23-00-00.000Z.json`，`gate.passed=true`：`reliability 20/20`、`boot-budget` 12/12 真实候选、`fixtures_over_budget` 仍只有那个永不 settle 的夹具。
- **已知且记录在案的不可复现面**：墙钟与 sample 时刻（`BS-32`）。同一夹具三次真跑的 `boot` 步是 21.7 / 25.4 / 28.6s，`boot→sample` 是 11.5 / 14.7 / 22.7s。**结论稳定，时间不稳定**——所以文档只给区间。

### 2.3 合规许可（licence / compliance）

- 沙盒仍只跑在本机临时目录，跑完即删；未读任何凭据文件；`quarantine/` 未动。
- ADR-0008 的授权来自 `audit/SIGNOFF.md` 的 R24 行（HUMAN 原话），本轮只执行已授权项。

## 3. 对抗性（专门想办法证明这轮是「假绿」）

| 反例 | 结果 |
|---|---|
| 「你只是把等待挪到别处了」 | 分段读数可查：`probe-adr0008e-overrun` 的 `sampleWaitMs 22700 ≈ sampleMtimeMs 22700`（差 13ms），`replacement.waited=false`、`waitedMs=0`。等待真的不在了，不是被改名 |
| 「`settled:false` 提前收敛会把本来能 `go` 的候选判成 `unknown`」 | 这是 E 的**已知代价**，但方向是**更保守**：`settled:false` 无论如何都不能出 `go`/`blocked`。29 份历史产物里「`settled:false` 后来被替换成可判样本」出现 **0 次**（`replacements_observed=0`）；`slow-plugin`（慢但会 settle）仍 `go` |
| 「`{error}` 的回归是假证明」 | **部分成立，已写明**：`{error}` 的等待由 `tests/unit/probe-host-sample.test.ts` 用**假 launcher** 驱动真实循环证明，**不是**真实 Host 写的。新开 `T-316`，并在 SIGNOFF 的「未逐条复核」栏点名 |
| 「顺手把默认窗口也降了吧」 | `git diff` 里 `unsettledReadinessMs = 20_000`、hook `timeoutMs ?? 15000`、`readinessTimeoutMs = 5_000` 全部未变 |
| 「文案里塞一个数字，下次又过期」 | 本轮特意把 `limits[]` 里的「≈48s」换成**不含具体秒数**的表述（只陈述结构），把数字留给带日期戳的产物与文档区间 |
| 「`d2_report` 用旧矩阵复算，等于没验新代码」 | **成立，已写明**：它的作用是证明报告/预算判定没被本轮改动弄坏，**不是** post-E 的分母重测。post-E 的矩阵重跑列为后续（`T-309` 长期项），本轮不动 20 次真跑预算 |

## 5. 口径（可直接引用）

> `ADR-0008` 方案 E 已实施：替换窗口只对 `{error}` 样本打开，`settled:false` 立即收敛。同一夹具的不可判 `boot` 步由 48.4s（R23）降到 28.6s（R26），产物里 `inventory.replacement_waited=false`。**判据与阈值未变**：`--unsettled-timeout` 仍 20000、`settle` 仍 15s、`boot→sample ≤20s` 仍是判据。
>
> **不许说**：①「probe 变快了 20 秒」（省下的是从未奏效的等待，且 sample 本身在波动）；②「不可判也在 20s 内」（当前 ≈29s）；③「`{error}` 路径已在真机回归」（只有假 launcher 单测）。
