## 3. 与 spec 的偏差（如实登记）

1. **P1（Host 内 `compat_inventory` 工具）未实现**。spec §4 把 P1 排在①，但 P1 需要真实 cordis 类型与一个能启动的 Host；本机没有 0.2.x 真机 profile（`HANDOFF.md` §8 既有阻塞项）。**先做 P2 不是偷懒，是为了不写一份无法被任何测试证明的 P1**：P2 与 P1 共用 `parseInventorySnapshot`，P1 只是把它搬到 `ctx.pluginInventory.list()` 后面。
   - 退出条件：本机装 `0.2.1-rc.3` profile → 在 profile 内跑 P1 → 同一份快照喂给 `audit --snapshot` 得到与 Host 内一致的结论。
2. **没有真机样本**：`data/fixtures/inventory/desktop-web-2026-10-26.json` 是合成样本。它证明的是**相位表与解析器**，不是「这台机器上某行真的处于 no-fiber」。产物 `sample.kind=synthetic` 与 `note` 已写明，禁止对外说成实测。
3. `agentPresets` 的 preset 维度**未实现**（spec §3 硬约束 3）。当前解析把 `agentPresets[].rows` 计成 **`unjudged` 通道**，并出一条 `unknown` + `missingEvidence:["missing.preset-phase"]`——**不再静默**（R7 独立复核发现原实现把它当已知键吞掉，见 §8）。登记为 `BS-15` / T-112。

## 8. 独立对抗性复核（外部上下文）与纠正

R7 交付后另起一个**只读、不看实现过程**的 adversary 会话（临时副本 + 目录联接 `node_modules`，不写仓库），任务是证伪 §1–§7。结论：**PARTLY CONFIRMED**——数字与映射全对，但有 3 处必须当场修、4 处要改口径。

| ID | 严重度 | 攻击 | 观测 | 处置 |
|---|---|---|---|---|
| **F1** | 高 | `agentPresets` 是否真的会「出现在 `unknownKeys`」 | **假的**：`agentPresets` 在 `KNOWN_SNAPSHOT_KEYS` 里，带 `fiberPhase: failed` 的 preset 行**完全不产生结论**、也没有警告 | **已修**：解析出 `unjudged: [{channel:'agentPresets', rows:n}]`，并出 `unknown`/`runtime.preset-unjudged`；新增 fixture + 单测 |
| **F2** | 高 | 产物是否写了 `sample.kind=synthetic` | **不是**：`render_inventory` 默认 `--sample fixture`，产物写 `kind:"fixture"`，而 HANDOFF/INDEX/spec/AUDIT 都写 synthetic；且 `--sample` 是自由文本，能凭空写 `live` | **已修**：删掉 `--sample`；kind 由导出文件自身声明决定（只有 `kind:"live"` + `sampled_at` 才标 live，否则 synthetic）；产物重新生成并更新步骤 sha256 |
| **F3** | 中 | 门是否真的「检查 spec 表」 | **没有**：把 spec 表里 `failed → blocked` 改成 `go`，门仍 `OK`（它只读手抄的 fixtures + `spec.includes(code)`） | **已修**：门解析 spec 表的**结论列首词**并与 fixtures 对账；同一攻击实测 → `FAIL spec-table:runtime.no-fiber` |
| **F4** | 中 | 「未声明」的文案对不跑的行是否撒谎 | 被禁用行同时出现在「in the sample but not declared」，文案说“runs” | **已修**：禁用行只报 `runtime.disabled`（跳过 undeclared）；文案改成「出现在采样里（相位 X）」 |
| **F5** | 中 | B3「相位缺失 → unknown」与代码 | 单行 `fiberPhase` 缺失 → `blocked/no-fiber`（不是 unknown）；原判据措辞把两件事糊在一起 | **已改口径**：B3 拆成「无采样 / 采样缺项 / 单行相位为 null」三种，并加 fixture 锁死 |
