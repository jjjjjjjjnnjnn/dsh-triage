# agent_collaboration（并发分工与留痕）

## 默认角色
Researcher → Implementer → Verifier → **Reviewer×4**（正确性 / 可复现 / 合规与许可 / SSOT 一致）+ **Adversarial Reviewer**（对抗性证伪）→ 主会话仲裁。

## 硬边界
- **同文件 / 同主题禁并行写**；只读审核可按维度并行。
- 审核任务**只读**：返回 `findings`（文件:行 + 问题 + 修复建议）+ `verdict: READY | NEEDS WORK`，由主会话统一改。
- 每轮 subagent 的 SessionID 记入 `audit/AI_DISCLOSURE_LOG.md`。

## 防上下文污染
- 每个 subagent 只给最小任务包（目标 + 输入文件 + 输出格式），不倒整仓上下文。
- 返回摘要式结论（verdict + ≤10 条证据点），证据贴 `文件:行号`，不贴大段原文。
- subagent 之间禁互相引用、禁串联；主会话拼图仲裁。

## 对抗性审核（强制，适用于任何门禁/判据/结论变更）
唯一 KPI：**能不能骗过这个门 / 这个结论**。必须输出：
1. **反例构造**：「故意做错但门仍 PASS」的具体输入（命令 + 预期输出），或明确写「未找到反例 + 已尝试角度清单」；
2. **盲区声明**：该门**看不见什么**（例如：admission 门看不见运行期冲突；probe 的 `/` 健康检查看不见白屏）；
3. **死指标核查**：新增的量是否真的进入 `conclusion` / SSOT（算了不判 = 缺陷）。

固定 9 角度清单（缺一即 NEEDS WORK）：输入缩放 / 单位换算 / 轴交换 / 退化输入 / 顺序置换 / 阈值边界 / 分母膨胀 / 抽样偏差 / 标签互换。
配额：同一门连续 2 个里程碑「未找到反例」→ 升级 HUMAN 裁决。
