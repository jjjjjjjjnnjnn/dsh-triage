# 模板 · Review Packet（审核包）

## 模板

```markdown
## 审核对象
- 产物：<提交 / PR / spec / 模块路径>
- 声称能做什么：<一句话（用于判断是否名副其实）>
- 判据来源：<docs/specs/...：#编号>

## 你的轴
<正确性 | 可复现 | 合规与许可 | SSOT 一致>（只报本轴，勿跨轴）

## 只读规则
- 不许修改任何文件
- 不许参考其他轴的结论（先独立上报）
- 不许只看实现者描述：必须打开产物本身

## 输出格式
- findings（每条：文件:行 — 问题 — 修复建议 — severity: block|warn|info）
- verdict: READY | NEEDS WORK
- 我看不见什么：<本轴盲区>
- 已检查且未发现问题的点：<≥3 条，证明不是走过场>
```

## 判定口径

| verdict | 条件 |
|---|---|
| `READY` | 无 block 级 finding，且每个 warn 都有明确处置（修或登记 blocked + owner） |
| `NEEDS WORK` | 任一 block，或存在无法复现的关键结论，或判据与实现不一致 |

## 反面示例（会被打回）

- 「整体看起来没问题」——没有具体证据点；
- 「跑通了」——跑通 ≠ 结论正确；
- 跨轴改结论（例：合规轴去质疑 admission 语义）；
- 只报问题不给修复建议。
